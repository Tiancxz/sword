第一章  项目概述
================================================================

1.1 基本信息
  名称（暂定）：宗门论道
  备选名：御剑对决 / 仙门攻防 / 阵破苍穹  [?]
  类型：实时策略卡牌（RTS-lite + 卡牌费用）
  题材：东方修仙 / 宗门大战
  平台：微信小游戏
  渲染：2D，原生 Canvas 2D（后期可迁 WebGL）
  美术：Spine 骨骼动画 + 序列帧 + 粒子特效
  后端：微信云开发（V1 纯本地，V1.5 上云）
  目标用户：18~35 岁，喜欢轻度策略、修仙题材、碎片化对战的玩家
  单局时长：3~5 分钟（180 秒 + 60 秒加时）

1.2 核心一句话
  皇室战争式的实时卡牌攻防，修仙皮——你与对手各据山门一座，
  实时派弟子出征、布阵拦截、长老施法，摧毁对方宗门大殿者胜。

1.3 设计目标
  ✅ 攻方能打穿（单位击杀后继续推进，不再"遇阵即停即没"）
  ✅ 双线互推有张力（双方同时攻守，永远有威胁）
  ✅ 看得懂（清晰新手引导，视觉反馈强）
  ✅ 修仙味（山道攻山、飞剑、阵法、灵兽）
  ✅ 碎片化（3~5 分钟一局，随时来随时走）

1.4 核心体验关键词
  紧张（实时对抗不等待）、策略（卡牌搭配与时机）、爽快（突破防线直捣大殿）、
  成长（弟子升级解锁更强流派）、社交（好友切磋排行竞争）

1.5 商业目标
  - V1.0 上线 3 个月：DAU 5,000+，次留 35%+，付费率 3%+
  - V1.5 上线 6 个月：DAU 20,000+，次留 40%+，付费率 5%+，ARPPU ¥15
  - V2.0 上线 12 个月：DAU 50,000+，实时 PvP 活跃占比 60%+

    每日游戏 30~60 分钟，看重公平与竞技感。

第三章  核心玩法设计
================================================================

3.1 玩法循环图

  ┌───────────────────────────────────────────┐
  │              单局实时对抗                    │
  │  ┌─────────┐    ┌──────────┐              │
  │  │ 灵力回复 │───→│ 出牌决策  │              │
  │  └─────────┘    └─────┬────┘              │
  │                       ↓                   │
  │  ┌─────────┐    ┌──────────┐              │
  │  │ 结算胜负 │←───│ 单位自动  │              │
  │  │ 获得奖励 │    │ 推进交战  │              │
  │  └────┬────┘    └──────────┘              │
  │       ↓                                   │
  │  ┌─────────┐                               │
  │  │ 养成升级 │→→→→ 下一局                   │
  │  └─────────┘                               │
  └───────────────────────────────────────────┘

3.2 实时核心循环
  - 无回合，无"你一招我一招"。时间持续流逝。
  - 灵力（费用）实时回复：每 2.8 秒 +1，上限随时间增长 5→10。
  - 玩家随时可出牌（只要灵力够），出牌后单位自动行动。
  - 单位 AI：自动寻路向敌方大殿推进，遇敌交战，击杀后继续前进。
  - 双方同时操作，互不等待——这是紧张感的来源。

3.3 单局流程
  1) 匹配/开始：双方大殿 30 血，灵力起始 5，计时 180 秒。
  2) 实时对抗：双方出弟子/布阵/施法，单位自动交战推进。
  3) 加时：若 180 秒平局，加时 60 秒，灵力回复加速 ×1.5。
  4) 结算：大殿血量先归零者负；均未归零则比剩余血量。

3.4 胜负判定
  - 摧毁对方大殿 → 立即胜利（"破山门"）
  - 时限到 → 大殿剩余血量高者胜
  - 加时仍平 → 灵力剩余多者胜 [?]

3.5 核心循环平衡保障

  攻方保障（能攻进去）：
    - 单位击杀后继续推进（不消失）
    - 阵法被毁格子有 8 秒冷却，不能无限补
    - 攻方有破阵工具（体修扛伤、五雷正法清阵、爆裂符换阵）
    - 灵力实时回复，攻方可持续出兵施压

  守方保障（能防下来）：
    - 阵法便宜性价比高（截脉阵费 2 血 4，换攻方更多时间）
    - 多阵叠加 + 特种阵法（寒霜减速、反震反伤、天罗范围）
    - 反制法术兜底（金钟罩免疫、移山倒海推后、困仙索定身）
    - 护山傀儡/灵兽提供肉盾拦截

3.6 操作方式
  - 出兵：点底部手牌 → 进攻单位直接入场（自动推进）
  - 布阵：点手牌 → 再点阵法区格子放置
  - 施法：点手牌 → 再点目标（单位/区域/大殿）
  - 费用不足时手牌灰显不可点
  - 手牌区始终显示 4 张牌 + 灵力条

3.7 地图与视角（折中方案）

  采用"折中方案"：逻辑上下直推 + 视觉山道攻山 + 两侧阵法区。

  ┌─────────────────────────┐
  │      [敌方大殿]         │  ← 对方核心（30血），顶端
  │  阵法区│主路│阵法区      │  ← 两侧可布阵拦截
  │       │    │            │
  │  阵法区│主路│阵法区      │  ← 中段，单位在此交战
  │       │    │            │
  │  阵法区│主路│阵法区      │  ← 下段
  │      [我方大殿]         │  ← 我方核心，底端
  └─────────────────────────┘

  - 主路：单位推进的通道，宽 1 格
  - 阵法区：主路两侧各 1 列，可布阵拦截（阵法不动）
  - 逻辑坐标系：y 轴向上为前进方向（0=我方大殿，MAX=敌方大殿）
  - 剑阵双方通用：攻方可铺阵掩护推进，守方可布阵拦截防守
  - 单位只需 2 朝向（上/下），美术成本可控

  视觉包装（修仙攻山味）：
  - 背景：山道蜿蜒向上，云雾缭绕，暗示"登阶攻山"
  - 大殿：山顶宗门建筑，受击震动+碎裂特效
  - 主路：石阶/云阶，单位沿阶行走
  - 阵法区：两侧悬崖/阵眼，阵法以光阵形式浮现

  为何放弃纯斜 45 度等距视角：
  - 美术成本 3~4 倍（每单位需 8 方向 vs 2 方向）
  - 碰撞复杂（菱形格子 vs 矩形 AABB）
  - 公平性难调（对角对称 vs 镜像对称）
  - 原生 2D 实现难度高

第四章  卡牌体系设计
================================================================

4.1 体系概述
  卡牌分两类：
    A. 人物卡（弟子/长老，出场自动行动）
    B. 技能卡（阵法/法术，即时或布设）
  剑阵类技能卡双方通用（攻方可掩护，守方可拦截）。

  A. 普通弟子（基础兵种）
  ┌──────────────┬──────┬──────┬──────┬──────┬──────┬──────────────────────────┐

  │ 宗门体修弟子  │  2   │  4   │  2   │ 1.0  │ 1.0  │ 普通近战士兵，基础兵      │

  │ 宗门御兽弟子  │  3   │  6   │  2   │ 0.8  │ 1.2  │ 控兽当肉盾，高血低速      │
  └──────────────┴──────┴──────┴──────┴──────┴──────┴──────────────────────────┘

  B. 精英长老

    - 阵法分支：自动补截脉阵
    - 符箓分支：天雷诀（清兵）
    - 丹药分支：阵法/大殿回血
    - 御兽分支：召唤护山灵兽

4.5 技能卡·法术（即时效果，需选目标）

  │ 名称      │ 费用 │ 效果                        │ 偏向        │

  │ 镇魂符    │  3   │ 指定敌方阵法失效3秒          │ 通用        │
  │ 金钟罩    │  3   │ 己方大殿免疫伤害3秒          │ 守方        │

  │ 天雷诀    │  4   │ 范围3格内敌方单位受4伤(清兵)  │ 守方/通用   │

4.6 卡牌稀有度
  凡品（普通）：基础兵种/基础阵法，易获取
  灵品（稀有）：特种单位/中阶法术，中期主力
  宝品（史诗）：精英长老/高阶阵法，核心卡
  仙品（传说）：V2+ 预留，特殊机制卡

4.7 卡组构筑规则
  - 卡组上限：8 张（V1），可重复携带同卡
  - 平均费用建议：3.0~3.5（低费快攻 / 高费坦克 / 均衡三种流派卡组）
  - 卡组预设：V1 提供 3 套预设卡组（快攻型/控制型/坦克型）

4.8 阵法机制（关键平衡点）
  - 阵法是"固定建筑"，布在阵法区格子，不动
  - 阵法有血量，被击毁后消失
  - 阵法被击毁的格子：8 秒内不能再布阵（冷却，防无限堵路）
  - 阵法攻击范围 1 格，会主动攻击经过的敌方单位
  - 剑阵双方通用：攻方铺阵掩护推进，守方布阵拦截

第五章  数值系统设计
================================================================

5.1 灵力系统
  - 实时回复：每 2.8 秒 +1
  - 上限：开局 5，每 30 秒 +1，封顶 10
  - 加时赛：回复速度 ×1.5
  - 卡牌费用区间：1~6

5.2 灵力时间表

  ┌──────────┬────────┬──────────┬───────────────────────┐
  │ 时间(秒) │ 灵力上限│ 累计回复量 │ 可出牌参考             │
  ├──────────┼────────┼──────────┼───────────────────────┤
  │   0      │   5    │    0      │ 开局：体修弟子(2)+阵法 │
  │  30      │   6    │   10      │ 可出金丹长老(6)        │
  │  60      │   7    │   21      │ 中期铺场期             │
  │  90      │   8    │   32      │ 双线高压期             │
  │ 120      │   9    │   42      │ 决战期                 │
  │ 150      │  10    │   53      │ 满灵力大招期           │
  │ 180      │  10    │   64      │ 时限结束/进入加时      │
  └──────────┴────────┴──────────┴───────────────────────┘

5.3 大殿血量与摧毁度
  - 大殿血量：30
  - 摧毁度 = 造成伤害 / 30 × 100%
  - 每次单位到达大殿造成伤害 = 单位攻击力
  - 大殿血量归零 = 立即失败

5.4 单位 DPR（每秒伤害）分析

  ┌──────────────┬──────┬──────┬──────┬──────┬──────┬──────────┐
  │ 名称          │ 攻击 │间隔(s)│ DPR  │ 血量 │ 费用 │ 性价比    │
  ├──────────────┼──────┼──────┼──────┼──────┼──────┼──────────┤
  │ 宗门体修弟子  │  2   │ 1.0  │ 2.0  │  4   │  2   │ 高(基础)  │
  │ 宗门剑修弟子  │  3   │ 1.3  │ 2.3  │  3   │  3   │ 中(远程)  │
  │ 宗门御兽弟子  │  2   │ 1.2  │ 1.7  │  6   │  3   │ 高(坦克)  │
  │ 金丹期长老    │  3   │ 1.5  │ 2.0  │ 10   │  6   │ 中(技能)  │
  │ 截脉阵        │  2   │ 1.0  │ 2.0  │  4   │  2   │ 高(防守)  │
  │ 万刃阵        │  3   │ 1.0  │ 3.0  │  5   │  4   │ 中(高输出)│
  │ 天罗阵        │  2   │ 1.0  │ 2.0× │  6   │  5   │ 中(范围)  │
  └──────────────┴──────┴──────┴──────┴──────┴──────┴──────────┘
  注：天罗阵 DPR 为单体值，实际可打多目标，总 DPR 更高。

5.5 费用效率模型（DPE = DPR / 费用）
  - 体修弟子 DPE = 2.0 / 2 = 1.0（基准）
  - 剑修弟子 DPE = 2.3 / 3 = 0.77（远程溢价）
  - 御兽弟子 DPE = 1.7 / 3 = 0.57（血量溢价）
  - 金丹长老 DPE = 2.0 / 6 = 0.33（技能溢价）
  - 截脉阵 DPE = 2.0 / 2 = 1.0（防守基准）
  设计原则：越贵的卡 DPE 越低，但附加价值（射程/血量/技能）越高。

5.6 推进速度模型
  - 棋盘长度：9 格（0=我方大殿，8=敌方大殿，含大殿格）
  - 体修弟子（移速1.0）：9 秒走完全程（无干扰）
  - 御兽弟子（移速0.8）：11.25 秒走完全程
  - 流光剑（移速1.6）：5.6 秒走完全程（突袭型）
  - 遇敌交战会停下，实际推进时间 >> 无干扰时间

第六章  AI 与关卡设计
================================================================

6.1 AI 设计目标
  - V1：提供 PvE 对手，能模拟真人操作节奏
  - AI 分 3 档难度：简单/普通/困难
  - AI 行为可预测但有变化，不完美（留出玩家操作空间）

6.2 AI 决策模型

  A. 灵力管理
  - 简单 AI：灵力够就出牌（随机选可出的牌）
  - 普通 AI：攒到 4+ 灵力出牌，优先出中费单位
  - 困难 AI：根据局势选牌（攻方压力大→布阵，己方推进顺→继续出兵）

  B. 出牌策略
  - 简单 AI：60% 出兵，40% 布阵，随机选牌
  - 普通 AI：根据己方大殿受威胁程度决定攻守
    - 大殿血量 > 60%：70% 出兵，30% 布阵
    - 大殿血量 30~60%：40% 出兵，60% 布阵
    - 大殿血量 < 30%：20% 出兵，80% 布阵+反制法术
  - 困难 AI：加入卡组协同（同流派连出触发羁绊效果[V1.5+]）

  C. 布阵位置
  - 简单 AI：随机选阵法区格子
  - 普通 AI：优先在大殿前 2~3 格布阵
  - 困难 AI：根据敌方单位位置针对性布阵（高速单位前方布寒霜阵）

  D. AI 思考间隔
  - 简单 AI：每 3.5 秒决策一次
  - 普通 AI：每 2.5 秒决策一次
  - 困难 AI：每 1.5 秒决策一次 + 反应型即时施法

6.3 PvE 关卡设计（V1.5+）

  ┌──────┬──────────┬────────────────────────┬────────────┐
  │ 关卡 │ 名称      │ AI 行为特征             │ 奖励        │

  │ 1-3  │ 外门切磋  │ 简单AI，只用基础兵      │ 灵石×100    │
  │ 4-6  │ 内门比试  │ 普通AI，加入阵法        │ 灵石×200    │
  │ 7-9  │ 长老指点  │ 普通AI，加入法术        │ 灵石×300    │
  │ 10   │ 宗门大比  │ 困难AI，全卡池          │ 弟子碎片    │

7.1 美术风格

  - 动画：Spine 骨骼动画
    - 每单位需：待机/行走/攻击/受击/死亡 共 5 套动画
    - 飞剑类：旋转+拖尾粒子替代行走
  - 尺寸：单位高 64~80px（适配 750×1334 设计稿）
  - 阴影：椭圆软阴影，统一光源（正上方）

7.3 阵法美术规范
  - 表现：地面光阵（俯视半透明），激活时粒子上升
  - 尺寸：64×64px 格子内
  - 状态：正常（完整光阵）/ 受击（闪烁）/ 被禁（灰暗）/ 冷却（半透明+倒计时）

7.4 大殿美术规范
  - 尺寸：占顶部/底部各 1 行（高 120px，宽满屏）
  - 状态：正常 / 受击（震动+碎屑）/ 濒危（裂纹+红光）/ 破碎（爆炸特效）
  - 血条：大殿上方，红绿渐变

7.5 特效规范
  - 命中：小型粒子爆发（4~6 粒子，0.3s）
  - 死亡：单位碎裂消散（0.5s）
  - 法术：全屏范围光效 + 粒子（0.8s）
  - 阵法激活：上升光柱（持续）
  - 大殿受击：屏幕震动 + 碎屑

7.6 UI 美术规范
  - 风格：水墨边框 + 半透明深色底
  - 手牌区：底部 4 张牌横排，选中态上浮+发光
  - 灵力条：手牌区上方，蓝色液条 + 数字
  - 计时器：屏幕顶部中央
  - 血量条：屏幕顶部两侧（我方左/敌方右）

7.7 V1 占位美术方案
  - 单位：纯色圆角矩形（攻方红/守方蓝），标注名称首字

8.3 渲染循环

  Director.tick(dt):
    1. update(dt)     // 更新游戏逻辑
       - 灵力回复
       - 单位移动/交战
       - AI 决策
       - 检查胜负
    2. render()       // 渲染
       - 清屏
       - 绘制背景（山道）
       - 绘制大殿
       - 绘制阵法
       - 绘制单位（按 y 排序，模拟深度）
       - 绘制特效
       - 绘制 UI（手牌/灵力/血量/计时）
    目标帧率：60fps（dt 上限 33ms 防大跳帧）

8.4 碰撞与寻路
  - 坐标系：y 轴向上为前进（0=我方大殿，8=敌方大殿）
  - 主路宽度：1 格（x=0），阵法区 x=-1 和 x=1
  - 单位移动：每帧 y += speed * dt * direction
  - 交战检测：AABB 矩形碰撞（同列 y 距离 < attackRange）
  - 目标选择：优先攻击同列最近敌方单位/阵法

8.5 性能优化策略
  - 单位按 y 坐标排序绘制（模拟深度遮挡）
  - 同屏单位上限：30（超出最老的消失或不生成）
  - 粒子池：复用粒子对象，避免 GC
  - 脏矩形：V2 考虑，V1 全屏重绘（单位少时够用）
  - 分包加载：主包核心代码 < 4MB，美术资源分包

8.6 数据结构

  Unit {
    id, cardId, owner(0/1), x, y,
    hp, maxHp, atk, speed, attackRange,
    attackInterval, lastAttackTime,
    target(Unit|null), state(walk/fight/dead),
    traits[], buffs[]
  }

  GameModel {
    time, // 剩余时间
    players: [{
      hallHp, hallMaxHp, energy, energyMax,
      deck[], hand[], drawPile[],
      units[], formations[]
    }, { ... }],
    state: playing/overtime/ended
  }

第十四章  质量验收标准
================================================================

14.1 V1 功能验收清单

  [必做] 实时核心循环
  [必做] 单位自动走/打/击杀后继续推进
  [必做] 灵力实时回复+手牌系统
  [必做] 3 弟子 + 金丹长老 + 5 阵法 + 8 法术
  [必做] AI 对手（简单/普通/困难）
  [必做] 折中视角渲染（主路+阵法区+山道背景）
  [必做] 胜负结算
  [必做] 新手引导（4 步）
  [必做] 占位美术（色块+简单动画）

14.2 性能验收标准
  - 真机 60fps（iPhone 12 / 中端安卓）
  - 同屏 20 单位不卡顿
  - 包体 < 4MB（主包）
  - 内存占用 < 150MB
  - 冷启动 < 3 秒

14.3 平衡验收标准
  - 模拟 10 局 AI vs AI：双方摧毁度 20%~70%
  - 胜率：攻守方各 40%~60%
  - 0% 摧毁度对局 < 10%
  - 90%+ 对局在 150~210 秒内结束

14.4 体验验收标准
  - 新手引导完成率 > 80%
  - 首局胜率 > 50%（AI 简单档）
  - 无崩溃 / 无死锁 / 无无限循环
  - 操作响应延迟 < 100ms

附录 B  术语表
================================================================

  灵力      = 费用资源（类似圣水/elixir），实时回复
  大殿      = 玩家核心，被摧毁即失败（类似国王塔）
  弟子      = 攻方进攻单位（人物卡）
  长老      = 精英单位，定期随机释放分支技能
  阵法      = 防守建筑（技能卡），布在阵法区，不动有血量
  法术      = 即时效果技能卡，需选目标
  摧毁度    = 对大殿造成的伤害比例
  灵石      = 软货币，养成用
  仙玉      = 硬货币，内购获取
  剑魄      = 特殊货币，弟子升星用
  境界      = 养成段位包装（练气/筑基/金丹/元婴）
  主路      = 棋盘中央单位推进通道
  阵法区    = 主路两侧布阵区域
  DPE       = DPR / 费用，费用效率指标
  DPR       = 每秒伤害（攻击力 / 攻击间隔）
