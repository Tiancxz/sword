## 上架流程说明 - 微信小游戏 / Steam / Google Play
## ============================================================
## 本文件为人工操作流程说明，非代码。
## 对应: I2.05 微信开发者工具测试 / I4.04 签名打包上架
## ============================================================

### 一、微信小游戏上架流程 (I2.05)

1. 准备工作
   - 注册微信小游戏账号: https://mp.weixin.qq.com/
   - 获取AppID和AppSecret
   - 下载微信开发者工具: https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

2. 导出游戏
   - Godot编辑器 → Project → Export → 选择"MiniGame (微信小游戏)"预设
   - 使用官方godot_for_minigame插件导出为.pck + index.html
   - 导出目录: export/wechat/

3. 微信开发者工具测试
   - 打开微信开发者工具 → 导入项目 → 选择export/wechat/目录
   - 填入小游戏AppID
   - 模拟器预览 → 真机预览（扫码在手机测试）
   - 调试控制台查看console.log和报错

4. 上传提审
   - 开发者工具 → 上传 → 填写版本号和备注
   - 登录mp.weixin.qq.com → 版本管理 → 提交审核
   - 审核通过后发布上线

### 二、Steam上架流程 (I3.04)

1. 准备工作
   - 注册Steamworks开发者: https://partner.steamgames.com/
   - 缴纳Steam Direct费用($100)
   - 获取AppID（已填入steam_appid.txt，当前480为测试用）

2. 安装GodotSteam插件
   - 下载: https://github.com/GodotSteam/GodotSteam
   - 放入addons/godotsteam/
   - Project Settings → Plugins → 启用
   - 配置steam_appid.txt为真实AppID

3. 导出游戏
   - Godot编辑器 → Project → Export → 选择"Steam (Windows桌面)"预设
   - 导出为.exe + .pck
   - 确保steam_api64.dll随exe一起分发

4. Steamworks后台上传
   - 登录Steamworks → 应用管理 → 上传构建
   - 使用SteamPipe工具上传: steamcmd + login + app_build脚本
   - 设置Depot → Store页面 → 定价 → 发布

5. 成就和云存档配置
   - Steamworks后台 → 统计与成就 → 添加成就（见SteamAchievements.gd的ACHIEVEMENTS常量）
   - 云存档 → 启用Steam Cloud → 配置云路径

### 三、Google Play上架流程 (I4.04)

1. 准备工作
   - 注册Google Play开发者: https://play.google.com/console
   - 缴纳注册费($25，一次性)
   - 生成release keystore:
     keytool -genkey -v -keystore zongmen.jks -keyalg RSA -keysize 2048 -validity 10000 -alias zongmen

2. 安装GooglePlayBilling插件
   - 下载: https://github.com/GodotNuts/GodotGooglePlayBilling
   - 放入addons/google_play_billing/
   - Project Settings → Plugins → 启用

3. 配置签名
   - 在export_presets.cfg的preset.2中填入keystore路径和密码
   - 或在Godot编辑器 → Export → Android → Keystore中配置

4. 导出AAB
   - Godot编辑器 → Project → Export → 选择"Android (Google Play)"预设
   - 导出格式选AAB (.aab)
   - 导出路径: export/android/宗门论道.aab

5. 签名对齐（如用命令行）
   - jarsigner -verbose -sigalg SHA256withRSA -digestalg SHA-256 -keystore zongmen.jks 宗门论道.aab zongmen
   - zipalign -v 4 宗门论道.aab 宗门论道-aligned.aab

6. 上传发布
   - 登录Google Play Console → 创建应用
   - 应用内容 → 商品详情 → 定价 → 隐私政策
   - 测试 → 封闭测试/开放测试 → 内部测试
   - 正式版 → 上传AAB → 提交审核 → 发布

### 四、注意事项

- 包名一致性: com.zongmenlundao.game 在Google Play和各平台保持统一
- 隐私政策: Google Play和微信均要求提供隐私政策URL
- 内容分级: 各平台均需填写内容分级问卷
- 截图素材: 准备至少4张游戏截图（各平台分辨率要求不同）
